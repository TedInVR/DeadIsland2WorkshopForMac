Reserve ammunition

Reserve ammunition is shared by weapons using the same ammo type. Restore Normal Maximum refills each type for the selected character. It adds missing types and consolidates duplicate stacks.

Changes stay staged until export or Finalize and Re-encrypt. Normal maximum: shells 30 · heavy rounds 30 · pistol rounds 75 · rifle rounds 90 · nails 60 · bolts 15 · disks 24. Back Up This Save
A new named folder keeps the original filenames and PS4 account/game folder structure. Existing backups are never replaced.


Named Save Backups
Restore encrypted backups to their original account/game folders on the selected drive. Any existing destination pair is backed up first. Decrypted Dead Island 2 backups open in the editor instead.


Finalize and Re-encrypt
This sends your validated edited save to GarlicSaves, re-encrypts it for the same PSN profile, decrypts the returned result to verify ownership and edits, backs up any current destination save and replaces it in the correct PS4 folder on the chosen drive. Keep Workshop open and the drive connected until “Saved to USB and verified” appears.

About this online service
Optional online service · Preview
Selected save files are sent to garlicsaves.com for processing on its console workers. This feature needs internet access and your worker key. Original USB saves are backed up. Finalize and Re-encrypt replaces the selected USB destination only after re-encryption and a verified backup; the package-only tools keep their results separate. Re-encryption includes extra service jobs to verify ownership and edited data before release. Console import still needs testing; individual games may have service restrictions.
Worker key & connection settings

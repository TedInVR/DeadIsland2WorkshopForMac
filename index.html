PS4 Decrypt / Encrypt · GarlicSaves
Optional online service · Preview
Selected save files are sent to garlicsaves.com for processing on its console workers. This feature needs internet access and your worker key. Original USB files are backed up and preserved. Live service processing and console import still need testing; individual games may have service restrictions.
Your key is saved securely on this computer in macOS Keychain or Windows Credential Manager and loads automatically next time. It is never included in app downloads, GitHub, settings files, logs, or backups.
1. Decrypt a USB save
Choose a save in USB Saves first.
2. Edit, then re-encrypt
After editing, click Encrypt Edited Copy. Workshop validates your current edits, preserves the companion files and sce_sys metadata, and sends the complete package back to the same PSN account. Test the resulting pair on a spare USB drive.
3. Transfer saves to another PSN profile
Resign one save, or every encrypted save on the source profile’s selected USB drive. Destination saves are backed up before processing and again before replacement. Processing depends on GarlicSaves support for the game.

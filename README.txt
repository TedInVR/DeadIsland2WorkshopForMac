DEAD ISLAND 2 WORKSHOP FOR MAC 0.16.0

Quit Workshop, extract this package, and double-click Install.command.
It updates /Applications/Dead Island 2 Workshop.app and opens the same app.
Needs macOS 12+, Python 3.9–3.13, and Apple Command Line Tools. Compression libraries are installed automatically into a private runtime.

Read USER_GUIDE.md or open User-Guide.html for full instructions.
In the app: Help > User Guide, Check for Updates, Download Updates,
Automatic Updates, Keyboard Shortcuts, and PS4 Decrypt / Encrypt.

Edit/create/delete/replace weapons in a decrypted PS4 export from Save Wizard.
Review & Export saves a separate copy. Import that copy through Save Wizard.
Optional GarlicSaves online decryption/re-encryption is available as a connection preview. Live game-data compatibility and console round-trip testing remain pending.
Test one change on PS4 and keep your original backup.

Updates: https://github.com/TedInVR/DeadIsland2WorkshopForMac
Downloads from the public repository do not require a GitHub login.
Automatic checks require authenticated GitHub CLI (gh) access on this Mac.
They run every 15 minutes with the app closed and leave it closed after updating.
No GitHub token or Save Wizard credentials are bundled in this package.

Optional GarlicSaves preview: PS4 Decrypt / Encrypt remembers your worker key securely on this computer. Test Connection sends no saves. Decryption/encryption requires explicit upload confirmation. Live output compatibility and PS4 import still need testing.

NAMED PRESETS
Save as Preset stores the current mod/perk set locally between launches. Choose a preset and Apply Preset to use it on another weapon; Delete Preset leaves applied weapon changes intact. Done applies a replacement in the editor. Review & Export or Encrypt Edited Copy saves the edited file. Toolbar labels now stay visible and have hover help.

0.15.0: Fill to 50% for the selected character (materials/parts 50; med-kits 5; fuses 3). Character levels in inventory choices. Right-click Copy Weapon / Paste Weapon uses a full snapshot and retains destination IDs. Ammo fill/revert controls distinguish selected-character from all-character scope. Per-weapon preset labels and Update Existing Preset selection. Export or encrypt to save game edits.

0.16.0: Finalize and Re-encrypt is the highlighted final action. It validates edits, checks the actual encrypted result through a fresh decryption, corrects an observed account byte-order reversal, verifies game data and keystone, then backs up and replaces the encrypted USB pair. A wrong account or failed verification stops USB installation. Additional GarlicSaves jobs take extra time; console acceptance still requires testing.

DEAD ISLAND 2 WORKSHOP FOR MAC 0.8.0

Quit Workshop, extract this package, and double-click Install.command.
It updates /Applications/Dead Island 2 Workshop.app and opens the same app.
Needs macOS 12+, Python 3.9+, and Apple Command Line Tools. No pip packages.

Read USER_GUIDE.md or open User-Guide.html for full instructions.
In the app: Help > User Guide, Check for Updates, Download Updates,
Automatic Updates, Keyboard Shortcuts, and Save Encryption.

Edit/create/delete/replace weapons in a decrypted PS4 export from Save Wizard.
Review & Export saves a separate copy. Import that copy through Save Wizard.
Built-in PS4 container decryption/re-encryption is not implemented.
Test one change on PS4 and keep your original backup.

Updates: https://github.com/TedInVR/DeadIsland2WorkshopForMac
For this private repository, browser downloads require your GitHub login.
Automatic checks require authenticated GitHub CLI (gh) access on this Mac.
They run every 15 minutes with the app closed and leave it closed after updating.
No GitHub token or Save Wizard credentials are bundled in this package.
